## ✨ Key Features

- **Soft Luxury Aesthetic**: Designed with a warm chocolate brown (`#4A2C2A`), cream, and bronze color palette for an elegant user experience.
- **Dynamic Horizontal Date Picker**: Custom interactive date strip with active state tracking and local timezone support.
- **Task Management**: Create, update, and organize tasks with custom priorities, descriptions, and start/end dates.
- **Progress Tracking**: Real-time dynamic task counter and visual progress indicators.
- **Custom UI Details**: Custom-styled luxury scrollbars and fully responsive layout structure.

---

## 🛠️ Tech Stack

- **Frontend**: React.js (Component Architecture, Hooks: `useState`, `useEffect`)
- **Styling**: Modern CSS3 (Custom Scrollbars, Flexbox, CSS Grid)
- **Deployment & Hosting**: Vercel
- **Version Control**: Git & GitHub
